# 해적선 · Tempest Corsair

브라우저에서 바로 항해하는 3D 해상 전투. 작은 범선으로 시작해 해적과 왕립 해군을 현측 포격으로 가르고, 보물을 건지고, 태풍을 버티며 선체·돛·함포를 키운다. 마지막 해역에는 크라켄이 있다.

그래픽과 효과음은 모두 절차적으로 만든다. 로그인, 외부 에셋, 유료 서비스는 쓰지 않는다.

## 요구 사항

- Node.js 22 이상
- 설치 후 네트워크는 필요 없다

## 설치와 실행

```bash
npm install
npm run dev
```

개발 서버는 [http://127.0.0.1:43123](http://127.0.0.1:43123) 이다.

## 빌드

```bash
npm run build
npm run preview
```

`dist/`에 정적 파일이 생긴다. 미리보기도 같은 포트 43123을 쓴다.

## 테스트

```bash
npm test
```

단계 진행, 강화, 현측 포격, 해적/해군 행동, 보물, 크라켄의 예고 후 강타, 태풍 경보를 검증한다. 브라우저에서 입력과 렌더링을 보려면:

```bash
npm run dev
node scripts/browser-smoke.mjs
```

## 조작

| 동작 | 키보드 | 터치 |
| --- | --- | --- |
| 돛을 펼쳐 전진 | `W` 또는 `↑` | 왼쪽 스틱 위 |
| 감속 | `S` 또는 `↓` | 스틱 아래 |
| 좌우 선회 | `A` `D` 또는 `←` `→` | 스틱 좌우 |
| 좌현 포격 | `Q` | 좌현 |
| 우현 포격 | `E` | 우현 |
| 가까운 적에게 조준 포격 | `Space` 또는 클릭 | 조준 |
| 일시정지 | `Esc` 또는 `P` | 정지 |
| 해역 다시 | 일시정지·패배 중 `R` | — |

좁은 화면이나 터치 기기에서는 가상 스틱과 포격 버튼이 나타난다. 좌현과 우현은 따로 장전된다.

## 플레이

1. 타이틀에서 **출항하기**. 기록이 있으면 **이어하기**와 **새 항해**가 있다.
2. 배를 움직여 현측이 적을 향할 때 포를 쏜다. `Space`는 더 잘 맞는 쪽을 고른다.
3. 금빛 상자는 금화다. 적을 격침해도 금화를 받는다.
4. 해역을 비우면 정비 화면이 열린다. 선체, 돛, 함포 중 하나를 고친다.
   - 선체: 최대 내구와 충돌, 뱃전의 높이
   - 돛: 속력·선회, 돛대 수
   - 함포: 포문 수와 일제사 피해
5. 해적은 거리를 좁히고 넓게 쏜다. 해군은 거리를 유지하고 더 정확하게 쏜다. 둘은 서로도 맞춘다.
6. 1해역에는 태풍이 없다. 이후 해역에서는 가끔 **태풍 경보** 뒤에 하늘이 어두워지고 비와 바람이 배를 민다.
7. 제3장 **크라켄의 눈**에서는 주황 원이 뜬 뒤 촉수가 내려온다. 원이 닫히기 전에 벗어나야 한다.

진행과 음향·화면 흔들림 설정은 이 브라우저의 `localStorage`에 남는다. 타이틀의 **새 항해**는 기록을 지운다.

개발 중에는 `?autostart=1&stage=0` 부터 `stage=5`, 그리고 `?upgrades=2` 로 특정 해역과 강화 상태를 바로 열 수 있다.

## 알려진 제한

- 배와 바다는 절차적 모형이라 역사 속 함선과 같지 않다.
- 바람은 태풍 이벤트의 밀림으로만 작용한다. 상수풍 항해 시뮬레이션은 없다.
- 효과음은 짧은 합성음이다.
- 싱글 플레이, 로컬 저장만 된다.
- 크라켄은 하나의 예고-강타 패턴을 분노 단계에서 더 빠르게 반복한다.
- 디버그 주소 매개변수는 일반 플레이 버튼이 아니다.

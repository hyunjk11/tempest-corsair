# 해적선 · Tempest Corsair

브라우저에서 바로 항해하는 3D 해상 전투. 한 바다의 양 끝 항구에서 작은 범선으로 시작해 고기와 중립 해적으로 배를 키우고, 아군 항구에서 선체·돛·함포를 산 뒤 적 항구를 부순다. 가운데에는 보물선과 크라켄이 있다.

그래픽과 효과음은 모두 절차적으로 만든다. 로그인, 외부 에셋, 유료 서비스는 쓰지 않는다.

## 요구 사항

- Node.js 22 이상
- 설치 후 네트워크는 필요 없다

## 설치와 실행

```bash
npm install
npm run dev
```

개발 서버는 [http://127.0.0.1:43123](http://127.0.0.1:43123) 이다.

## 빌드

```bash
npm run build
npm run preview
```

`dist/`에 정적 파일이 생긴다. 미리보기도 같은 포트 43123을 쓴다.

## 테스트

```bash
npm test
```

단계 진행, 강화, 현측 포격, 해적/해군 행동, 보물, 크라켄의 예고 후 강타, 태풍 경보를 검증한다. 브라우저에서 입력과 렌더링을 보려면:

```bash
npm run dev
node scripts/browser-smoke.mjs
```

## 조작

키는 배의 기준이다. 카메라가 뱃머리 뒤를 따라가므로 화면 위가 앞이고, 왼쪽 키가 좌현, 오른쪽 키가 우현이다.

| 동작 | 키보드 | 터치 |
| --- | --- | --- |
| 뱃머리 방향(화면 위)으로 전진 | `W` 또는 `↑` | 왼쪽 스틱 위 |
| 감속 | `S` 또는 `↓` | 스틱 아래 |
| 좌현으로 선회 | `A` 또는 `←` | 스틱 왼쪽 |
| 우현으로 선회 | `D` 또는 `→` | 스틱 오른쪽 |
| 좌현 포격 | `Q` | 좌현 |
| 우현 포격 | `E` | 우현 |
| 가까운 적에게 조준 포격 | `Space` 또는 클릭 | 조준 |
| 시야 넓히기 | `Z` | 넓게 |
| 일시정지 | `Esc` 또는 `P` | 정지 |
| 다시 출항 | 일시정지·승패 중 `R` | — |

좁은 화면이나 터치 기기에서는 가상 스틱과 포격 버튼이 나타난다. 좌현과 우현은 따로 장전된다.

## 플레이

한 판은 양쪽 항구가 있는 한 바다다. 온라인 대전도, 도시 건설도 없다.

1. **출항하기**. 소리는 그 클릭 뒤에 켜지고, **소리 켜짐 / 소리 꺼짐**으로 끈다. 예전 해역 저장은 설정만 남기고 그 챕터로 이어가지 않는다.
2. 아군 항구 근처에서 고기 떼를 스치면 선체가 회복되고 금화가 조금 는다. 같은 떼는 바로 다시 건질 수 없다.
3. 붉은 중립 해적은 어느 쪽 편도 아니다. 가까이 있는 배를 치고, 쓰러뜨리면 금화와 경험이 오른다.
4. 아군 항구로 돌아가 레벨이 된 선체·돛·함포를 산다. 배가 눈에 띄게 커진다.
5. 약 70초 뒤에 보물선, 그 뒤에 크라켄이 가운데로 온다. 첫 1분에는 태풍이 없다.
6. 적 항구의 포와 수비선을 뚫고 항구를 부수면 이긴다. 아군 항구가 무너지면 진다. 플레이어가 침몰하면 8초 뒤 아군 항구로 돌아오고, 금화 일부를 잃는다.

`Z`는 따라가는 카메라를 잠깐 높인다. 오른쪽 아래 지도에는 양쪽 항구, 섬, 고기, 함대가 항상 보인다.

## 알려진 제한

- 배와 바다는 절차적 모형이라 역사 속 함선과 같지 않다.
- 바람은 태풍 이벤트의 밀림으로만 작용한다. 상수풍 항해 시뮬레이션은 없다.
- 효과음은 짧은 합성음이다.
- 싱글 플레이, 로컬 저장만 된다.
- 크라켄은 하나의 예고-강타 패턴을 분노 단계에서 더 빠르게 반복한다.
- 디버그 주소 매개변수는 일반 플레이 버튼이 아니다.
